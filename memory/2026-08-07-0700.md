## 防火墙恢复 bug 修复(用户实测反馈)
- 症状:恢复防火墙后仍关闭,Windows 安全中心显示"某些设置由你的组织管理"
- 根因(两层):
  1. RestoreCommandBuilder 自动生成的恢复命令 = Set-NetFirewallProfile -Enabled True + Remove-ItemProperty 删除本地 EnableFirewall → 启用后又删值,配置变"未配置"
  2. HKLM\SOFTWARE\Policies\Microsoft\WindowsFirewall\*\EnableFirewall=0 + DisableNotifications=1 组策略残留未清理 → 安全中心判定"由组织管理",组策略优先级压过本地配置
- 修复:恢复命令改为 启用 + 清理 Policies 组策略残留(删 Profile 子键,空父键一并删);不再删除本地 FirewallPolicy\EnableFirewall
- 实测闭环(提权):关闭→False / 恢复→True / 策略键清除 / 本地值=1 ?
- 冒烟测试新增 3 条防火墙恢复断言 → 157 PASS 0 FAIL
